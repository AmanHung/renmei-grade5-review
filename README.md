# 小小複習室

模擬考新增：三上、五上各科各一份固定 A 卷，共 10 卷；每卷 20 題 × 5 分＝100 分，全部答完送出才批改。草稿依名字存於本機，整卷交卷後同步作答和總成績。命題範圍與配分見 [模擬考命題藍圖.md](模擬考命題藍圖.md)。驗證另執行 node test-mock-exams.cjs。

仁美國小三上、五上五科考前複習，支援 iPad、姓名分流、錯題與 GAS 作答紀錄。

[開啟網站](https://amanhung.github.io/renmei-grade5-review/?grade=3)｜[考題參考與刪重](考題參考與刪重.md)

## 題庫品質（6.0.0）

每個年級各 13 組、260 個重點；三上 454 題、五上 464 題，合計 918 題。

- 先查閱公開考卷，再依已核對版本範圍調整；題型參考與原題明確區分，不假稱官方原卷。來源包含學校公開數學、國語、英語、自然與社會考卷，部分同版本課程資料另用作範圍核對。
- 不再湊每單元 100 題。原 3,400 題退役 2661 題、加入 179 題；數學刪除換數字模板，三上角 10 個不同任務、五上平面圖形 20 題。
- 國語每組 20 篇；英語、自然與社會每組 4 篇不同情境，一篇 5 題。自然與社會另有每單元 20 題精選觀念應用。國語三上順序題改用具體事件，主旨的干擾選項也改為其他合理主旨，不用一個正面口號對三個明顯錯誤口號。
- 依本模式題庫大小提供 5／10／20／40 題，最多抽一半；先未練、再避開上一份。每題題號不重複，並盡量分散任務與減少純基礎題。
- 數學計算可紙筆運算後填數字，判斷與理由題用選擇；三上角不加入角度數計算。配圖支援放大，閱讀整篇送答後看解析與題型來源。

## 孩子如何使用

在 iPad Safari 開啟網站，輸入名字或暱稱，選年級與單元。可使用 Safari 分享選單「加入主畫面」。同一台裝置可切換名字。

名字是紀錄標籤，不是帳號驗證。重點、抽題歷史、錯題與成績保存在瀏覽器，不同裝置不自動合併。舊作答與完成成績保留，退役題號不改成新題；錯題畫面只列目前有效題目。

每次作答與完成練習會送到家長的 GAS；收到回執才標示同步，離線資料保留待補傳。紀錄含圖卡資料與年級單元，不放到 GitHub，不需孩子登入 Google。後端見 [GAS設定說明.md](GAS設定說明.md)。

## 本機維護與發布

執行 `node prepare.mjs` 產生題庫、來源頁、題庫清單與刪重報告；執行 `node preview.mjs` 後以 http://127.0.0.1:4173 預覽。教材模組在 curriculum/，審題與來源由 quality-review.mjs、assessment-sources.mjs 管理。

檢查：`node validate.cjs`、`node test-reading.cjs`、`node test-visuals.cjs`、`node test-grades.cjs`、`node test-gas.cjs`。會檢查唯一任務、抽題不重複、完整閱讀組、圖上實際角度、數字評分及 GAS 寫入去重。

推送 main 後 GitHub Actions 先測試，再發布 dist/ 到 GitHub Pages。

版本與範圍證據見 [三上版本核對.md](三上版本核對.md)、[版本核對.md](版本核對.md)。
