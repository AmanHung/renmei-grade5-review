## 孩子如何使用

在 iPad Safari 開啟網站即可選年級與單元，不需輸入密碼。可使用 Safari 分享選單「加入主畫面」。三上使用「言旭」，五上使用「悠晴」；另提供測試模式。

重點、抽題歷史、錯題與成績先保存在瀏覽器，雲端紀錄在背景合併，連線慢或暫時離線也能繼續做題。舊作答與完成成績保留，退役題號不改成新題；錯題畫面只列目前有效題目。

每次作答與完成練習會送到家長的 GAS；收到回執才標示同步，離線資料保留待補傳。紀錄含圖卡資料與年級單元，不放到 GitHub，不需孩子登入 Google。後端見 [GAS設定說明.md](GAS設定說明.md)。

## 本機維護與發布

執行 `node prepare.mjs` 產生題庫、來源頁、題庫清單與刪重報告；執行 `node preview.mjs` 後以 http://127.0.0.1:4173 預覽。教材模組在 curriculum/，審題與來源由 quality-review.mjs、assessment-sources.mjs 管理。

檢查：`node test-v12.cjs`、`node test-all-subject-visuals.cjs`、`node validate.cjs`、`node test-reading.cjs`、`node test-visuals.cjs`、`node test-grades.cjs`、`node test-gas.cjs`。會檢查唯一任務、抽題不重複、完整閱讀組、圖上實際角度、數字評分及 GAS 寫入去重。

推送 main 後 GitHub Actions 先測試，再發布 dist/ 到 GitHub Pages。

版本與範圍證據見 [三上版本核對.md](三上版本核對.md)、[版本核對.md](版本核對.md)。
# 家長後台

開啟 `parent.html`，可查看各孩子的單元進度、成績趨勢、錯題與完整練習歷程。支援本機紀錄、原試算表 CSV 匯入及免密碼雲端查詢。雲端功能需更新原 Apps Script 部署，詳見 [GAS 設定說明](GAS設定說明.md)。驗證指令：`node test-parent.cjs`。

年級自動綁定學習者：三上為「言旭」、五上為「悠晴」，不再選擇或輸入姓名；按「切換成測試者」可進入測試模式（也支援 `?test=1`），統一記為「測試」。既有「晴晴」「洪悠晴」合併為「悠晴」，其他暱稱歸為「測試」。後台預設不下載測試紀錄，勾選「顯示測試紀錄」才會讀取。

孩子雲端進度：孩子與家長後台均免密碼，開啟頁面後在背景讀取雲端資料。進度分為「各科進度條 → 各單元進度條」，以已作答的不同題號計數，重做不重複累加。作答、成績、錯題、閱讀標記、抽題紀錄及模擬考草稿皆同步至原 Google Sheet；本機僅作為快取與離線待傳佇列。

配圖修訂版 17（2026-11-02）：逐題核對五科練習與 A、B 卷。注射筒、倒扣杯、葉片、聲光器材等使用具體裝置與構造圖，英語呈現人物、飲料與水果數量，國語與社會依題意呈現告示、流程、地形與位置。表格作為補充紀錄，不能取代需要觀察的器材或空間圖。審查紀錄見「各科配圖重新審查.md」。

C 卷（2026-11-04）：新增三上、五上各五科，合計 330 題。依孩子目前已保存的進度優先選曾答錯及未作答題；保留完整閱讀組、單元涵蓋與各科 100 分。詳見 [C 卷出題說明](C卷出題說明.md)。檢查：`node test-exam-c.cjs`。

免密碼與背景同步修正（2026-11-05）：移除孩子與家長登入；C 卷依目前可用紀錄立即出題，空白裝置或同步失敗也能開卷。背景更新不覆蓋正在作答的考卷。雲端首次載入後只取新增紀錄，iPad 返回分頁、重新顯示頁面或恢復網路時自動補傳；未收到成功回執的資料仍保留待傳。同步失敗不會中斷作答。驗證：`node test-cloud.cjs`、`node test-parent.cjs`、`node test-exam-c.cjs`。
