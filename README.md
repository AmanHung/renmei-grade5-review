# 小小複習室

仁美國小五上五科第一次月考的互動複習網站（國語／英語／自然／社會康軒、數學翰林），支援 iPad、姓名分流及 GAS 作答紀錄。

網站：https://AmanHung.github.io/renmei-grade5-review/

## 孩子如何使用

在 iPad Safari 開啟網站，輸入名字或暱稱，例如「晴晴」，選單元讀重點或開始練習。可從 Safari 分享選單選「加入主畫面」，日後直接點圖示開啟。

同一台裝置可切換不同名字，分別保存閱讀進度、題目抽取歷史、錯題及成績。名字只作為紀錄標籤，不等於帳號驗證。

## 本機預覽

在此資料夾執行 `node preview.mjs`，瀏覽 `http://127.0.0.1:4173`。
直接開啟 `dist/index.html` 亦可閱讀與作答；進度保存取決於瀏覽器對本機檔案的儲存支援。

## 更新教材

編輯 `curriculum/` 內的教材模組（literacy.mjs 為國英閱讀，math.mjs 為數字填答），執行 `node prepare.mjs` 重新產生 `dist/content.js` 及「題庫清單.md」。上層的內容草案保留第一版研究與來源紀錄。

## 功能

- 五科篩選、13 組；每組 20 個重點提醒、100 題，共 260 個重點與 1,300 題。
- 自然、社會各單元保留 40 題單選、20 題是非、20 題多選、20 題配對；國英共 80 篇原創短文、400 題閱讀；數學 500 題數字填答。
- 每次可選 10、20 或 40 題，依該單元題型比例抽題，優先未抽題並避開上一份題目。
- 單選與多選的選項、配對右側說明會重排；是非維持「正確／錯誤」順序。
- 每題 1 分，多選須完全選齊、配對須三組全對，成績換算百分制後比較歷次最佳。
- 每次抽題會記錄抽取歷史，未完成離開仍視為抽過；題庫用盡後持續隨機練習。
- 五個重點一頁，可逐一標記已讀；錯題可混合題型重練，答對後移除。
- 沿用舊版儲存鍵，保留歷次練習成績與對應錯題；擴充後閱讀進度改為逐項標記。
- 使用瀏覽器 localStorage 依名字保存紀錄；不同裝置的本機進度不會自動合併。
- 每次確認答案記錄名字、單元、題目、作答內容、是否正確及耗時；完成後另記錄整份成績。
- 設定 GAS 後，待傳資料收到寫入回執才標示同步完成；離線時保留佇列，重新連線後補傳。
- iPad 直向與橫向以頂部導覽呈現，重點文字 18 px、作答選項至少 64 px 高，避免窄側欄壓縮閱讀區。
- 作答紀錄只送到家長自己的 GAS，不提交到 GitHub。GAS 不公開查詢孩子姓名、作答或紀錄表連結。

後端部署與欄位說明見 [GAS設定說明.md](GAS設定說明.md)。未設定 GAS 時，畫面會明確標示「紀錄保存在這台裝置」。

## GitHub Pages

推送 `main` 後，`.github/workflows/pages.yml` 會執行題庫與 GAS 模擬測試，並部署 `dist`。不需要付費伺服器或孩子的 Google 登入；GAS 是否允許匿名送出，依家長選擇的部署設定。

教材依據、課名與核對限制見 [版本核對.md](版本核對.md) 及頁尾的「教材與使用說明」。題目為自行編寫，含同概念的不同題型與生活應用，非出版社官方題庫。

## 驗證

執行 `node validate.cjs` 檢查題量、唯一題號、選項重排與評分、抽題比例、相鄰試卷不重複及題庫遍歷；執行 `node test-gas.cjs` 驗證紀錄寫入、去重、回執及輸入驗證。

國語／英文閱讀模式：每篇完整文章配 5 題，10／20／40 題分別抽 2／4／8 篇，文章只顯示一次，五題可往返選答，全部完成後一次送出與看解析。閱讀錯題重練會補齊同篇題目，最多 20 題。逐題紀錄的作答秒數為該篇總耗時平均分配，非逐題精確計時。
